# FPT Cloud Internship Report

## Giới thiệu

Báo cáo quá trình thực tập tại FPT Cloud với định hướng
Data Analytics / Data Engineering.

## Nội dung thực tập

- Data Warehouse
- Data Modeling
- SQL
- Python
- Power BI
- DBT
- DBeaver

## Dự án

### Online Sales Data Modeling

Thực hiện xây dựng mô hình dữ liệu cho tập dữ liệu Online Sales,
xử lý dữ liệu bằng DBeaver và DBT, sau đó trực quan hóa dữ liệu
bằng Power BI.

### Sale Pipeline

Hỗ trợ xây dựng và trực quan hóa một số bảng dữ liệu Sale Pipeline.
